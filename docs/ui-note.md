# UI 说明：家电

- **谁在什么时刻打开**：给家电刚坏的住户。
- **首屏任务句**：这台家电，修还是换。
- **主操作**：按「说清故障 → 先过安全关 → 拿走报修单」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：售后服务台；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：售后服务台。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给家电刚坏的住户：选型号、说故障、交代已经做过的安全操作，先判断能不能继续用，再对照维修报价和换新成本。
